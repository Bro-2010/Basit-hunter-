BASIT: SHADOW HUNT
===================

A lightweight original HTML5 Canvas survival/action game starring BASIT.

FILES
- index.html
- style.css
- game.js

HOW TO PLAY
1. Put all three files in the same folder.
2. Open index.html in a browser, or use Acode preview.
3. On Android, use the joystick to move and ATTACK to fire.
4. Use the 💥 button for the area blast.
5. Survive, collect coins/crystals, level up, and beat your high score.

FEATURES
- Top-down survival gameplay
- BASIT player character
- Three enemy types
- Coins, crystals, shield and magnet power-ups
- Area blast ability
- Levels and combo scoring
- High score and coin saving with localStorage
- Sound effects generated in JavaScript
- Pause/resume
- Touch controls plus keyboard fallback
- No external libraries, images, servers, APIs, or databases

The game is designed to be lightweight and friendly to mobile browsers and GitHub Pages.
